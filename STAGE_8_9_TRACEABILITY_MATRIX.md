**Method.** Statuses follow baseline §9: *Implemented* = verified in code **and** by an executed test/direct evidence; *Partial*; *Missing*; *Blocked* (needs an external specification or approval); *Not Verified*. This is an independent re-assessment, not a copy of the Stage 8.4 addendum.

**Totals (counted from the rows below):** Implemented 7 · Partial 19 · Missing 0 · Blocked 0 · Not Verified 0. Items that are only *partly* verifiable are kept as Partial with the unverified part named in "Remaining work". No row is "Implemented" against an approved requirement.
